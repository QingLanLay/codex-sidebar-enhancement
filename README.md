# Codex 侧栏增强

为 Windows 版 Codex 桌面客户端提供侧栏、会话快捷栏、历史提问和设置面板增强。当前分发版本为 **0.4.27**。

![Codex 侧栏增强当前功能布局示意图](侧栏增强功能概览.png)

图示要点：①最近项目排序；②设置与额度显示；③最新提问置顶的历史栏；④收起后窗口右下角的“历史”入口；⑤位置稳定、玻璃质感高亮的运行会话；⑥完成且已查看的会话归到快捷栏右侧。此图为功能示意图，并非 Codex 实际界面截图。

## 一键安装

- [Windows 安装包（支持符合条件的热更新）](exports/Codex侧栏增强-0.4.27-Windows.zip)
- [交给其他 Codex 的一键安装说明](exports/Codex侧栏增强-0.4.27/交给其他Codex一键安装.md)
- [功能、兼容范围与卸载说明](work/README.md)

当前安装包面向 Windows Codex **26.917.9434.0** 和 Node.js **22+**。安装器会校验兼容性；已安装版本且运行页面可连接时可热更新，否则按安装器提示在下次启动时加载。请先阅读安装说明，不要单独提取或修改安装包内文件。

## 项目文件

- `work/sidebar-toggle.js`：侧栏增强主脚本。
- `work/inject.cjs`、`work/Launcher.cs`：注入监视器与 Windows 启动器源码。
- `exports/Codex侧栏增强-0.4.27/`：当前发行版文件、SHA-256 清单和安装/卸载脚本。
- `exports/Codex侧栏增强-0.4.27-Windows.zip`：可分发安装包。

安装包及源码不包含开发机聊天记录、数据库、额度密钥或运行日志。仓库公开仅表示可查看；当前未附加开源许可证。
